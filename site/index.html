What is available today

This page introduces the product; it does not accept your documents. The installed local app runs on your computer. Automatic English names require a one-time model download and can miss names. Placeholders are reversible redaction, not encryption. Supports UTF-8 text and a restricted set of text-only Word files. No cloud requests from the desktop app. Review every export; this is not guaranteed anonymization. Restoration maps contain private plaintext.
